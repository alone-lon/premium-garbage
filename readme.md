# 精品垃圾 · PREMIUM GARBAGE

> 520 件精心设计、郑重排版、官方口吻的单页藏品——然后严格保证毫无用处。

**线上展览**:<https://alone-lon.github.io/premium-garbage/>

这是一个「认真生产垃圾」的系列项目:每一件藏品都是一个独立 HTML 单页,零依赖、双击即开,用最严肃的形式承载最无意义的内容。从第 1 件「精品垃圾认证中心」到第 520 件「系列收官纪念堂」,全系列 520 件,已完结。

## 三无标准

每一件藏品,必须同时满足:

- **无用**:不解决任何实际问题,不提供任何有效信息
- **无害**:不收集数据、不请求网络、不含跟踪脚本
- **无负担**:单文件,零依赖,双击即开,看完即走

## 仓库结构

```
index.html          展览总目录(含全部 520 件链接)
001.html ... 520.html   藏品本体(以拼音命名,如 zuijinshanchu.html)
batch*.js           概念数据文件(每炉 18-40 件,生产线的历史档案)
factory.js          生产线:读取 batch 数据 → 生成单页 + 重建目录
audit.js            质检:语法 / ID / 标签静态扫描
runtime-audit.js    渲染后 DOM 全量扫描(无头浏览器)
runtime-audit2.js   控制台异常全量扫描(无头浏览器)
dedupe-check.js     概念查重:编号 / 文件名 / 藏品名 / 近似名
```

## 生产线流程

1. 手写 `batchN.js` 概念文件(标题 / meta / 描述 / 交互数据 / 结语 / 页脚彩蛋)
2. `node factory.js batchN.js` —— 生成页面、追加目录、编号冲突自动拦截
3. `node audit.js` —— 静态质检,零问题放行
4. `node runtime-audit2.js` —— 无头浏览器全量扫描控制台异常(全量约 10 分钟)
5. 提交推送 → GitHub Pages 构建 → 线上验证
